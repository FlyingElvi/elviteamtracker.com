Privacy Policy

Last updated: September 30, 2026

The short version. The bot stores Discord ids — server, channel, and your user id if you link yourself — plus public EA match data. It cannot read your messages: it never requested that permission from Discord. Nothing is sold, shared, or used for advertising, and there is no analytics on this website. Ask and your link is deleted.

1. Who is responsible

Elvi's Team Tracker is an independent personal project run by one individual, not a company. That person is the data controller for everything described here, and is reachable through the support server linked at the bottom of this page.

2. What is stored

Field by field, this is everything the bot keeps.

About your Discord server

StoredWhen
Server id and server nameWhen the bot is added.
Channel idsThe channels you told it to post in — scores, and any sign-up sheet the server runs.
Role idsOnly the roles you explicitly hand it — a manager role, or a role given to people who sign up for something.
Message ids of its own postsSo it can edit a box score when the game is re-read, instead of posting it twice.
Which clubs the server follows, and howThe club, the channel, the emoji, and the match filter you chose.
The league the server plays, and its calendarOnly if a manager sets it up: the league, its game times, schedule and clock, and its seasons and weeks.

About you, as a Discord user

StoredWhen
Your Discord user id, linked to your in-game player id, platform and in-game nameOnly when you run /trackme. Nothing links you to a gamertag until you do.
Your user id on a sign-up sheet or a lineupWhen you click to answer one.
What you type into the bot's own dialogsOnly when you type it — a note for the players, a comment between coaches, a name for a week. Stored as typed, and shown where you put it.
Your user id on a server roster used to gate optional featuresOnly on servers where those features are switched on.

That's the whole list. The bot stores no Discord username, avatar, email address, IP address or payment information — it never receives them in the first place, and it has no accounts and no login.

About matches

Club id, platform, club name and club logo settingsFor every club a server follows.
Match records — id, type, timestamp, the two clubs, goals, shots, resultStraight from EA.
Per-player match lines — in-game player id, in-game name, position, the statistics of that game, and a computed ratingThis is EA's own public data. It exists whether or not the player has ever touched this bot, and whether or not they are on Discord at all.

3. What is not stored

  • Message content. The bot does not have Discord's Message Content intent. It is technically incapable of reading what people write, in any channel, including ones it can see. The only text it keeps is what you type into its own dialogs, listed above.
  • Direct messages. Never read, never stored.
  • Voice. The bot never joins a voice channel.
  • Your member list, beyond the roster described above on the servers that use it. It is a list of ids and nothing else — no names, no join dates, no roles.
  • Anything about you as a person — no email, no real name, no location, no device or browser information, no advertising identifiers.

4. Why it is stored

Each thing is stored for exactly one reason, and that reason is to make a feature work:

  • Server, channel and club settings, so the bot knows where to post and what to follow.
  • The /trackme link, so that when EA says a player scored, the bot knows whose /playercard that belongs to. Without it the bot simply doesn't know who you are, and every player-facing command says so.
  • Match data, so leaderboards, head-to-head records and cards have a history to read.
  • Message ids, so posts can be updated rather than duplicated.

None of it is used for profiling, advertising, or anything other than showing you hockey statistics in the server that asked for them.

5. Data that comes from EA

Match and player statistics are read from EA's public NHL Pro Clubs endpoints — the same records the official EA companion app shows to anyone. The bot sends EA nothing about you or your Discord server; it only asks for club and match records. Your in-game name and stats being visible there is a function of the game, not of this bot.

6. Who can see it

  • Anyone in a Discord server that follows your club can see the box scores and leaderboards posted there. That is the point of the bot.
  • Nobody else. Data is not sold, rented, licensed, shared with advertisers or analytics companies, or handed to any third party.
  • The maintainer can see the database, because it runs on their machine.
  • It may be disclosed if the law actually requires it — which has never happened.

7. Where it lives

On a single self-hosted server in Canada, in one SQLite database. There is no cloud provider, no third-party database service, and no data warehouse. Backups are taken nightly, kept on the same premises, and retained for about two weeks before being overwritten.

This is a hobby project on home hardware. It is protected with reasonable care — the bot has no inbound network port at all, and the database is not reachable from the internet — but no system is perfectly secure, and you should assume that anything you put into a Discord server could conceivably leak.

8. How long it is kept

  • Server settings are kept while the bot is in the server. Removing the bot or running /stoptracking removes the link.
  • Your /trackme link is kept until you ask for it to be deleted, or until you relink to a different gamertag.
  • Match records are kept indefinitely. They're a historical record of games that were played, they are derived from public EA data, and other servers' leaderboards depend on them. Removing the bot from your server does not erase games that happened.

9. Getting your data removed

Ask in the support server and it will be done — normally the same week, and you don't have to give a reason.

  • Unlink yourself: your /trackme row is deleted. Your Discord id stops being connected to any gamertag anywhere in the database.
  • Remove your sign-ups: your id is cleared from every sign-up sheet and lineup.
  • A whole server: a server admin can ask for every row belonging to their server — settings, channels, sign-ups — to be deleted.

What can't be undone is the existence of a match. A game's per-player line stays, because it is EA's public record of a game other people also played in. After you unlink, it is no longer connected to your Discord account.

You can also ask for a copy of everything held about you, in the same place.

10. Children

The bot is not directed at children. Discord's own Terms of Service set the minimum age for using Discord at all — 13 in most countries, higher in some — and the bot is only usable through Discord. Nothing is knowingly collected from anyone below that age. If you believe a child's data is in there, say so in the support server and it will be removed.

11. This website

This site is static pages hosted on GitHub Pages. There are no cookies, no analytics, no tracking pixels, no advertising and no embedded third-party scripts. Nothing here profiles you. As with any web host, GitHub receives the requests your browser makes to load the pages; their handling of that is covered by GitHub's privacy statement.

12. Changes to this policy

If what the bot stores changes, this page changes with it, and the date at the top is updated. Anything material will also be announced in the support server. Old versions are visible in this site's public page history.

13. Contact

Privacy questions, data requests, deletion requests, or anything at all about the bot: the Elvi's Team Tracker support server on Discord.
