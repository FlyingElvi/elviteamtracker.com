1. What this is

Elvi's Team Tracker (the "bot") is a Discord application that follows EA NHL Pro Clubs matches and posts them, along with player statistics, in Discord servers that have added it. It is an independent personal project, maintained by one person in their own time, and it is free to use.

By adding the bot to a Discord server, or by using any of its commands, you agree to these terms. If you don't agree with them, don't add it, and remove it if it's already there.

2. Who can use it

You need to be old enough to use Discord in the first place — that's Discord's own requirement, which is 13 in most places and higher in some. You also need permission to add applications to the server you're adding it to (Discord enforces this: adding the bot requires the Manage Server permission).

3. Acceptable use

Don't do these things:

  • Automate, script or hammer the bot's commands in a way that isn't a person using it normally.
  • Try to break it, overload it, get into parts of it you weren't given, or work around a permission check.
  • Use it to harass anyone, or to build a case against someone using their stats.
  • Link yourself to a gamertag that isn't yours, or otherwise put false identity data into it.
  • Resell it, rebrand it, or present it as something you made.

The bot may be removed from a server, or a particular person may be blocked from using it, if any of the above happens. No notice is owed, though you will usually get one.

4. Availability, and the right to change it

The bot runs on a self-hosted machine. There is no uptime guarantee, no service level agreement, and no support obligation. It may be offline for maintenance, because of a bug, because EA's own data service is down, or because the power went out.

Features may be added, changed, restricted to certain servers, or removed at any time. Some features are deliberately enabled server by server rather than everywhere. The bot may be discontinued entirely — if that happens, reasonable notice will be posted here and in the support server.

5. Your data

What gets stored, why, and how to have it deleted is set out in the Privacy Policy, which is part of these terms.

Statistics the bot produces are derived from EA's own public match records. They can be wrong: EA's data can be incomplete, a game can be recorded oddly, and the bot's own logic can have bugs. Nothing it posts is authoritative, and it shouldn't be used to settle anything that actually matters.

9. Ending it

You can stop at any time: run /stoptracking to stop following a club, or remove the bot from the server (Server Settings → Integrations, or right-click the bot → Kick). It keeps nothing running once it's out of a server.

What happens to already-stored data when you do that — and how to have it deleted rather than just disconnected — is covered in the Privacy Policy.
